# maps/ — the photo of each campsite

One drone photo per campsite, named after it:

    C3.jpg      C9.jpg      DJK.jpg

jpg, png or webp. It is shown on the result card as it is — nothing is drawn on
it, nothing is calibrated, no tent is pointed at. Tap it and it opens full size.

No photo for a campsite means no picture on that card. The build says which ones
are missing.

The CAD drawings are never shown to guests. They are only read for the tent
count, model and size.

## Taking the photo

- Camera straight down over the block.
- The whole campsite in frame with some ground around it — the track, the road,
  the containers are what people navigate by.
- After the tents are up.
- Any size. The photo is embedded in the page, so watch the page size in the
  build output — around 150 kB per photo keeps the page comfortable on festival
  mobile data.
